## 사용법

### 마크다운을 PDF로 만들기

```bash
python 도구/_md2html.py 산출물/화면정의서.md "화면 정의서"
```

생성된 `.html` 을 브라우저에서 열고 `Ctrl+P` → 대상을 `PDF로 저장` 으로 지정합니다.
A4 여백·표 테두리·페이지 나눔이 인쇄용으로 설정되어 있습니다.

### CSV를 Excel에서 열기

CSV는 **UTF-8 BOM** 으로 저장되어 있어 더블클릭만 해도 한글이 깨지지 않습니다.
제출 양식(xlsx)이 정해져 있다면, CSV의 데이터 행을 복사해 양식에 붙여넣으면 됩니다.
