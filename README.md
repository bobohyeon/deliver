소스코드는 별도 저장소([OCR_MiniProject](https://github.com/ParkSehyeon1009/OCR_MiniProject))에 있습니다.

- **팀** 김보현(팀장) · 최재정 · 박세현
- **미니 프로젝트** 종료 — 코드 프리즈 8/5(수) · 발표 8/7(금)
- **본프로젝트** 진행 중 — 마감 9/13(일) · 발표 9/14(월).
  미니 프로젝트를 **버리지 않고 확장**한다. 아래 문서들은 그대로 본프로젝트의 기준선이다

본프로젝트의 일정·규칙·인수 상태는 `관리/작업인수인계.md` 하나만 읽으면 파악된다.

## 사용법

### 마크다운을 PDF로 만들기

```bash
python 도구/_md2html.py 산출물/화면정의서.md "화면 정의서"
```

생성된 `.html` 을 브라우저에서 열고 `Ctrl+P` → 대상을 `PDF로 저장` 으로 지정합니다.
A4 여백·표 테두리·페이지 나눔이 인쇄용으로 설정되어 있습니다.
화면 이미지는 상대 경로(`캡처/…`)로 연결되므로 **`.html` 을 `산출물/` 안에서 열어야** 이미지가 보입니다.

### CSV를 Excel에서 열기

CSV는 **UTF-8 BOM · 쉼표 구분** 으로 저장되어 있어 더블클릭만 해도 한글이 깨지지 않습니다
(결정사항 29). 제출 양식(xlsx)이 정해져 있다면 데이터 행을 복사해 양식에 붙여넣으면 됩니다.

> **주의** — Excel이 CSV를 A열에 몰아서 여는 경우가 있습니다. 그대로 저장하면 열 구분이
> 사라지고 인코딩이 CP949로 바뀝니다(ISS-037). 저장 시 형식을 **`CSV UTF-8(쉼표로 분리)`** 로
> 지정해 주세요.

## 화면 구성 (6종)

| ID | 화면 | 경로 | 담당 |
|---|---|---|---|
| `HOME` | 홈 (서비스 소개) | `/` | 최재정·김보현 |
| `LIST` | 문서 목록 + 상세 패널 | `/documents` | 김보현 |
| `DTL` | 문서 상세 (전체 화면) | `/documents/{id}` | 김보현 |
| `UPL` | 문서 업로드 및 분석 | `/upload` | 최재정 |
| `CMP` | OCR 엔진 비교 | `/ocr-compare` | 박세현 |
| `NF` | 페이지 없음 (404) | 정의되지 않은 모든 경로 | 박세현 |
