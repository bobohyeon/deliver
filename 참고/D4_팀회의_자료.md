### 발견·해결한 버그 2건

**① 요약 .txt 줄바꿈 누락**
`document_service.py`에서 `"".join(lines)` — 구분자가 빈 문자열이라 파일 전체가 한 줄로 뭉쳤음. `"\n".join(lines)`으로 수정.

**② 상세 조회 500 에러**
`document_router.py`에서 `AnalysisResponse(result=...)`로 생성했으나, 스키마에 `validation_alias="result_json"`이 걸려 있어 `result=`로는 채울 수 없음(Pydantic v2 규칙). `AnalysisResponse.model_validate(analysis)`로 변경 — `analysis_router.py`와 같은 방식.

**두 버그의 공통 원인: E2E 검증에 "상세 조회"와 "다운로드 파일 열어보기"가 빠져 있었음.**
→ 앞으로 검증 항목에 추가: HTTP 200이 아니라 **결과물 내용까지** 확인.

## 2. 결정 요청 사항

### ★ ① `App.jsx` 라우터 전환 (박세현님) — 가장 급함

현재 `App.jsx`는 `useState`로 main/test 화면을 토글하는 구조. **이것 없이는 목록·상세 화면을 앱에 연결할 수 없음.**

제안 구조:

| 경로 | 화면 | 담당 |
|---|---|---|
| `/` | MainPage | 박세현 |
| `/upload` | TestPage | 박세현 |
| `/documents` | ListPage | 김보현 |
| `/documents/:id` | DetailPage | 김보현 |

- `react-router-dom` 이미 설치됨 (7.18.2)
- **기존 MainPage / TestPage 코드는 수정 없음** — 라우트에 연결만 함
- 로그인 추가 시 `ProtectedRoute` 자리를 주석으로 남겨둠

### ② 레이아웃 — 하이브리드로 조합

의견이 갈린 게 아니라 **서로 다른 화면을 보신 것**으로 정리했습니다.

| 화면 | 채택 |
|---|---|
| 목록 | 안1 (테이블) — 열 7개 → **5개**로 축소 |
| 상세 | 안2 (우측 구성) |
| 업로드 | 안3 (드롭존 + 진행단계) |

`DocumentDetail`을 별도 컴포넌트로 분리해서, 나중에 안1 우측 패널로 옮겨도 **수정 비용 0**입니다.

목록 5열: `파일명 / 카테고리 / 요약 / 상태 / 업로드일`
(`extract_method`는 목록 응답에 없어 상세에만 표시)

### ③ 다크모드 미지원 (라이트 고정) 제안

- `index.css`에 `prefers-color-scheme: dark`가 있어서 **발표장 PC 설정에 따라 화면이 달라짐**
- 3명 화면의 색상 변수를 모두 통일하는 작업이 필요해짐
- → 본프로젝트 항목으로 기록하고, 미니프로젝트는 라이트 고정

### ④ 공통 컴포넌트 레이어

CSS 변수만 공유하면 버튼·배지가 각자 달라집니다. 3층 구조 제안:

```
Layer 1  디자인 토큰 (tokens.css)        ← 김보현
Layer 2  공통 컴포넌트 (Badge/Spinner/…)  ← 김보현
Layer 3  각자 페이지                      ← 각자
```

**기존 MainPage / TestPage 리팩토링은 강제하지 않습니다.** 새로 만드는 화면부터 쓰면 됩니다.

### ⑤ `prompts.py` 오타 수정 요청 (1글자)

```python
"category" : "선택한 카테고리".      # ← 마침표
"reason" : "..."
```

쉼표여야 합니다. **LLM에게 깨진 JSON을 예시로 주는 상태**라, 실연동 시 파싱 실패 위험이 있습니다.

### ⑥ 카테고리에 "약관"을 어떻게 넣을지 ★ 결정 필요

최재정님 확인대로 **표준계약서는 당사자·금액이 빈칸인 서식**이라 요약할 내용이 없습니다.
대안은 **약관**(조항이 완성된 문서)인데, 분류 라벨을 정해야 합니다.

| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| A | `계약서` 유지, 약관을 계약서로 분류 | 카테고리 변경 없음 | LLM이 `기타`로 보낼 수 있음 |
| B | `계약서` → **`계약·약관`** 으로 변경 | 분류 정확도 상승 | `prompts.py` 목록 1줄 수정 |

**B안 권장** — 수정 비용이 1줄이고, 실제 수집 가능한 문서와 라벨이 맞습니다.
