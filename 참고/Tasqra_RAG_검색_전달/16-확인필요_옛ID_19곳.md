# 옛 ID 19곳 — 1:1 매핑이 없어 판단이 필요하다

`16-stale-feature-ids.patch` 에 **넣지 않은** 것들이다. 기능명세서 부록 B 가
**"1:1 로 단정하지 말 것"** 이라고 명시한 구간이라, 확인 없이 바꾸지 않았다.

> 부록 A(`RAG` 12건 · `VIS` 9건)는 전수 확인된 매핑이라 44곳을 기계적으로 바꿨다.
> 아래 19곳은 `AMT`·`ANL`·`TSK` 로, 부록 A 에 없다.

## 확인받을 것 셋

1. **`AMT-01`** — `AMT-001-1`(추출) 하나인가, `AMT-001-2`(승인·수정)까지 걸치는가.
   `schemas/amount.py` 는 분석기 출력 스키마이므로 추출 쪽으로 보이는데,
   `models/enums.py:47` 쪽 문맥도 같은지 확인이 필요하다
2. **`ANL-03`** — 1→3 이므로 주석을 어떻게 쓸지. `ANL-002-1~3` 로 묶어 쓸까,
   셋을 나열할까
3. **`TSK-03`** — 원래 뜻이 "AI 가 태스크를 자동 등록하지 않는다" 인지 확인.
   그렇다면 승인(`TSK-002-1`)이 맞다

## 하지 않은 이유

인수인계 11절과 정정 문서가 같은 실패를 세 번 기록했다 — **일부만 보고 전체를
단정한 것.** 부록 B 가 명시적으로 경고한 구간에서 추측으로 바꾸면 **틀린 ID 가
코드에 박히고, 다음 사람이 그것을 근거로 읽는다.** 44곳을 먼저 확실하게 바꾸고,
19곳은 확인 뒤에 바꾸는 편이 안전하다.
