# Tasqra 로고 시안 2차 — TQ와 문서 T

첨부 원본은 파랑→청록 색감만 참고하고 행성 형태에서는 벗어났다. 모든 시안은 18px부터 44px까지 같은 마크를 쓰는 것을 전제로 한다.

## TQ 모노그램

| 시안 | 핵심 |
|---|---|
| TQ1 링과 화살표 | Q 링 안의 T, Q 꼬리는 실행 방향 |
| TQ2 솔리드 모노그램 | 면이 있는 Q로 앱 아이콘 같은 존재감 |
| TQ3 오픈 모노그램 | 열린 Q로 가볍고 기술적인 인상 |

## 문서가 모이는 T

| 시안 | 핵심 |
|---|---|
| DOC1 겹친 문서 T | 겹친 문서들이 하나의 T로 정리됨 |
| DOC2 접힌 문서 T | 문서 안의 T로 서비스 성격을 즉시 전달 |
| DOC3 모이는 문서 T | 여러 문서 흐름이 T로 합쳐지는 동작 표현 |

`TQ_문서T_비교.html`에서 흰 배경 44·30·18px와 네이비 사이드바 30px를 함께 비교한다.
