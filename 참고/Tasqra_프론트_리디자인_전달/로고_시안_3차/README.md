# Tasqra 로고 시안 3차 — 리본 T

이전의 원·행성·별·배지·문서 아이콘 표현을 중단하고, 접힌 리본과 문서 흐름을 하나의 `T` 실루엣으로 추상화했다.

| 시안 | 방향 |
|---|---|
| 01 플로우 리본 T | 가장 매끈한 한 덩어리 실루엣, T에서 실행 체크로 연결 |
| 02 폴드 리본 T | 접힌 앞뒤 면을 강조해 리본의 입체감과 개성을 강화 |
| 03 컨버지 T | 좌우 문서 흐름이 중앙 T로 합쳐지는 구조 |
| 04 레이어 T | 얇은 문서 레이어가 하나의 T로 정리되는 구조 |

`리본T_비교.html`에서 116px, 44px, 30px, 18px와 실제 네이비 사이드바 30px를 비교한다.

제품 코드에는 아직 반영하지 않았다. 방향 선택 후 선택안 하나만 선 굵기와 여백을 다듬어 최종 적용한다.
