# Tasqra 사이드바 로고 시안

원본의 파랑→청록 그라데이션과 `T` 인상을 유지하면서 30px 사이드바에서 식별되도록 단순화한 시안이다.

| 시안 | 방향 | 특징 |
|---|---|---|
| A | 컴팩트 행성 T | 원본 분위기를 가장 많이 유지하고 별·이중 궤도만 제거 |
| B | 라운드 배지 T | 작은 앱 아이콘처럼 안정적이며 30px에서 가장 선명 |
| C | 오픈 오비트 T | 면적을 줄여 가볍고 기술적인 인상 |
| D | 모션 모노그램 T | 행성보다 흐름·실행 이미지를 강조 |

`시안_비교.html`에서 흰 배경 44/30/18px와 실제 사이드바 배경 30px를 함께 비교할 수 있다.

현재 메인 헤더는 원본 PNG를 유지하고 52px에서 44px로 줄이는 방향이다. 시안 선택 전에는 제품 코드의 사이드바 로고를 변경하지 않는다.
