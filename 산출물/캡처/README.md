# 화면 캡처 보관 폴더

화면정의서(`../화면정의서.md`)가 참조하는 캡처 이미지를 이 폴더에 넣는다.

| 파일명 | 화면 | 비고 |
|---|---|---|
| `HOME.png` | 홈 · 서비스 소개 | 기능 메뉴 hover 상태 |
| `LIST.png` | 문서 목록 | 상세 패널 닫힌 상태 (5열) |
| `LIST2.png` | 문서 목록 + 상세 패널 | **핵심 화면** — 4열 + 우측 패널 |
| `DTL.png` | 문서 상세 (전체 화면) | 원문 접힌 상태 |
| `UPL.png` | 문서 업로드 및 분석 | 01·02·03 단계가 모두 보이게 |
| `CMP.png` | OCR 엔진 비교 | 두 엔진 결과 카드가 보이게 |

## 번호 표기 규칙

캡처 위에 **숫자만** 표기한다. 화면정의서의 요소 ID 뒷자리와 대응된다.

```
캡처의 01  →  LST-01 (문서 목록 제목)
캡처의 03  →  LST-03 (새 문서 업로드 버튼)
캡처의 30  →  LST-30 (상세 패널)
```

화면마다 접두어가 다르므로(`HOME` `LST` `DTL` `UPL` `CMP`) 숫자만으로 충돌하지 않는다.

## 번호 넣는 방법

1. `Win + Shift + S` 로 화면 캡처
2. PowerPoint에 붙여넣기
3. `삽입 > 도형 > 타원` → 숫자 입력 → 요소 위에 배치
4. 슬라이드 우클릭 → `그림으로 저장` → 위 표의 파일명으로 저장

> 그림판보다 위치 조정이 쉽고 번호 스타일이 통일된다.
