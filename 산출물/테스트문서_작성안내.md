### 확인 방법 예시

**DB 반영 확인**

```
docker compose exec db psql -U postgres -d pdfbrief -c "SELECT (SELECT count(*) FROM documents) AS docs, (SELECT count(*) FROM extracted_texts) AS texts, (SELECT count(*) FROM analyses) AS analyses;"
```

**한글 검색 확인** — PowerShell 에서 `curl` 로 한글을 넘기면 인코딩이 깨지므로 아래 방식을 사용합니다.

```
"제안자","제 안 자","   ","zzzz없는단어" | ForEach-Object { $r = Invoke-RestMethod ("http://localhost:8000/api/documents?q=" + [uri]::EscapeDataString($_)); "[$_] -> $($r.total)건" }
```

**응답 시간 측정**

```
$start = Get-Date
$res = curl.exe -s -X POST http://localhost:8000/api/documents -F "file=@경로\파일.pdf"
"소요 {0:N1}초" -f ((Get-Date) - $start).TotalSeconds
$res | ConvertFrom-Json | Select-Object id, char_count, page_count, extract_method
```

## 4. 참고: `참고/단위테스트_상세체크리스트.csv`

**제출용이 아니라 실제 시험할 때 옆에 두는 체크리스트**입니다 (81건).
에러 코드, 파라미터 경계값, 결과가 나오지 *않아야* 하는 경우까지 포함되어 있습니다.

### 반드시 확인해야 하는 회귀 항목

과거에 실제로 발생했던 결함이므로 이번 시험에서 재확인합니다.

| 항목 | 확인 방법 | 놓쳤던 이유 |
|---|---|---|
| **요약 파일 줄바꿈** | 다운로드한 `.txt` 를 **열어서** 확인 | 응답 코드와 파일명만 보고 통과 처리 |
| **문서 상세 조회** | 상세 화면이 정상 표시되는지 | 목록·분석은 정상인데 상세만 실패 |
| **본문 검색** | 자간이 나뉜 단어(`제안자`)로 검색 | 문서에 있는데도 검색되지 않음 |
| **공백만 검색** | 결과가 **전체 건수**인지 | 필터가 걸리면 안 되는 경우 |
| **없는 단어 검색** | 결과가 **0건**인지 | 조건이 무시되어도 결과가 나오면 구분 불가 |
| **에러 안내 문구** | AI 분석 실패 시 보조 안내 표시 | 정의되지 않은 코드명 사용 |
| **표 병합** | 표 이미지 추출 결과에 행 구분자 포함 | 좌표 기준이 어긋나 조용히 건너뛰어짐 |
| **삭제 후 연관 데이터** | 세 테이블 건수가 함께 감소하는지 | cascade 미설정 시 고아 데이터 발생 |

> 위 항목 중 **"공백만 검색"과 "없는 단어 검색"** 처럼 결과가 나오지 *않아야* 하는 경우를 확인하지 않으면, **필터가 아예 동작하지 않는 상황을 발견할 수 없습니다.**
