## 참고 문서: `참고/단위테스트_상세체크리스트.csv`

**제출용이 아니라 실제 시험할 때 사용하는 체크리스트**입니다 (81건).
에러 코드, 파라미터 경계값, 결과가 나오지 *않아야* 하는 경우까지 포함되어 있어 빠뜨리는 항목을 줄일 수 있습니다.

### 반드시 확인해야 하는 회귀 항목

과거에 실제로 발생했던 결함이므로 이번 시험에서 재확인합니다.

| 항목 | 확인 방법 | 놓쳤던 이유 |
|---|---|---|
| **요약 파일 줄바꿈** | 다운로드한 `.txt` 를 **열어서** 줄바꿈 확인 | 응답 코드와 파일명만 확인해 통과 처리됨 |
| **문서 상세 조회** | 상세 화면이 정상 표시되는지 | 목록·분석은 정상인데 상세만 실패 |
| **본문 검색** | 자간이 나뉜 단어(`제안자`)로 검색 | 문서에 있는데도 검색되지 않음 |
| **에러 안내 문구** | AI 분석 실패 시 보조 안내 표시 | 정의되지 않은 코드명을 사용해 매칭 실패 |
| **표 병합** | 표 이미지 추출 결과에 행 구분자 포함 | 좌표 기준이 어긋나 조용히 건너뛰어짐 |
| **없는 단어 검색** | 결과가 **0건**인지 | 조건이 무시되어도 결과가 나오면 구분 불가 |

> 마지막 항목처럼 **"나오지 않아야 하는 경우"를 확인하는 시험**을 빼면, 필터가 아예 동작하지 않는 상황을 발견할 수 없습니다.
