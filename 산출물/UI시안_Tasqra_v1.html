이 목업은 실제 앱이 아니라 파일 하나짜리 시안입니다. 색은 CSS 변수 20여 개로만 정해져 있어서 답만 정해지면 값을 바꾸는 작업입니다.

  1. 테마 — 오른쪽 위 버튼으로 네이비 ↔ 딥바이올렛을 바꿔 볼 수 있습니다. 어느 쪽이 나을까요?
  2. 사이드바 — 왼쪽 위 ☰ 로 접었다 펼 수 있습니다. 기본을 펼친 상태로 둘까요, 접힌 상태로 둘까요?
  3. 밀도 — 지표를 큰 카드 8개가 아니라 작은 타일 5개 + 강조 카드 1개로 줄여 한 화면에 넣었습니다. 이 정도가 읽기 좋은지, 아니면 숫자를 더 크게 보고 싶은지요?
  4. 강조 대상 — 지금은 금액 승인 대기를 어두운 카드로 강조했습니다. 그 자리에 더 급한 지표가 있을까요? (예: OCR 검수, 처리 실패)
  5. 우주 느낌의 범위 — 로고·사이드바·강조 카드까지만 어둡게 두고, 데이터 영역은 흰 바탕에 검은 글씨로 차분하게 뒀습니다. 조달 금액과 문서를 다루는 화면이라 숫자에 색을 얹으면 신뢰가 떨어진다고 봤습니다. 동의하시나요?
  6. “열린 태스크 —” 표시 — 아직 셀 수 없는 지표를 0 이 아니라 — 로 뒀습니다. 0 으로 두면 “할 일이 없다”로 읽히기 때문입니다. 이 표시가 이해되시나요?
