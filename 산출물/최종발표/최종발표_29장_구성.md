## 발표에서 금지할 표현

- 기능명세 97건을 “테스트 97건 통과”로 표현하지 않는다.
- 단위 79개·통합 70개 절차를 “149개 통과”로 표현하지 않는다.
- GitHub Actions 실행이 없으므로 CI 통과라고 말하지 않는다.
- `R@5 92.1%`를 `R@1 90%` 달성으로 표현하지 않는다.
- 하이브리드 검색을 BM25 또는 점수 가중합으로 설명하지 않는다. 실제 구현은 `ILIKE + word_similarity`, pgvector, RRF다.
- 일반 QA를 의미적 사실 검증 완료라고 표현하지 않는다. 서버가 검증하는 것은 근거 ID 계약과 범위다.
- S3/MinIO, Kubernetes, 자동 LLM 연쇄, dead-letter queue, Worker autoscaling을 구현됐다고 말하지 않는다.
- 단일 멀티태스크 파인튜닝 모델을 완성했다고 말하지 않는다. 현재는 요약·분류 모델 2개다.
- 임베딩 모델 선택 20번과 재정렬 모델 21번을 같은 평가 조건의 전후 비교로 표현하지 않는다.
