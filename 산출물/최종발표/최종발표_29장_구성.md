# Tasqra 최종 발표 29장 구성

기준: 2026-09-10 현재 **총 35장**. **김보현 1~21번 → 박세현 22번부터 전환.**

20번과 23~31번은 세현님이 만든 슬라이드이며, 원본 PNG(`세현님_원본_PNG/`)의 좌상단 번호만
새 순서로 바꿔 `전체본/교체용_PNG/` 에 넣었다. 20번은 발표자 표기도 김보현으로 바꿨다.
번호 교체는 **`도구/pptx/renumber_pngs.py`** 가 하고, 교체 뒤 원본과 번호 위치가 같은지
스스로 검사한다. 눈으로 맞추지 않는다.

내가 SVG 로 만드는 장은 **1~19번, 21·22번, 32~35번**이다.
32~35번은 세현님 구간이 늘어나면서 번호가 밀린 마무리 4장이라 `after31` 모드로 다시 매겼다.

**19~21번은 시간 순서다** — 모델을 고르고(19 · 김보현 평가셋), 그 모델을 학습시키고
(20 · 세현님 평가셋), 학습된 모델의 후보 범위별 성능을 재서(21 · 세현님 평가셋)
재정렬(22)로 넘긴다. **19번과 20·21번은 평가셋이 달라 수치를 이어 붙이지 않는다.**

## 발표에서 금지할 표현

- 기능명세 97건을 “테스트 97건 통과”로 표현하지 않는다.
- 단위 79개·통합 70개 절차를 “149개 통과”로 표현하지 않는다.
- GitHub Actions 실행이 없으므로 CI 통과라고 말하지 않는다.
- `R@5 92.1%`를 `R@1 90%` 달성으로 표현하지 않는다.
- 하이브리드 검색을 BM25 또는 점수 가중합으로 설명하지 않는다. 실제 구현은 `ILIKE + word_similarity`, pgvector, RRF다.
- 일반 QA를 의미적 사실 검증 완료라고 표현하지 않는다. 서버가 검증하는 것은 근거 ID 계약과 범위다.
- S3/MinIO, Kubernetes, 자동 LLM 연쇄, dead-letter queue, Worker autoscaling을 구현됐다고 말하지 않는다.
- 단일 멀티태스크 파인튜닝 모델을 완성했다고 말하지 않는다. 현재는 요약·분류 모델 2개다.
- 임베딩 모델 선택 20번과 재정렬 모델 21번을 같은 평가 조건의 전후 비교로 표현하지 않는다.
