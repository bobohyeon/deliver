# Tasqra 통합기능테스트명세서

| | |
|---|---|
| 기준 | `관리/기능명세서.md` (v5 통합판, 116건 — `DLV-001-3` 신규 추가분 포함) |
| 테스트ID 규칙 | `IT-` + 기능ID (예: `IT-AUTH-001`) — 기능명세서와 1:1 대응 |
| 작성 방식 | 완료 판정 문장을 그대로 옮기지 않고, 각 항목의 **설명 + 완료 판정**을 근거로 실제 절차(무엇을 하고 무엇을 보는지)를 만들었다 |
| 「수행결과」칸 | **비워 뒀다.** 사용자가 직접 완료/미완료/부분 을 적는다 |
| 「비고」칸 | 알려진 함정·선행 미구현으로 검증이 제한되는 이유 등을 미리 적어 뒀다. 추가로 적어도 된다 |
| `미구현` 항목 | 절차를 만들지 않고 **테스트 보류**로 표시했다. 구현되면 그때 절차를 채운다 |
| 검토 시점 | 사용자가 「수행결과」를 다 채운 뒤, 마지막에 통째로 검토한다 |
