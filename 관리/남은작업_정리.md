## 5. 오늘 밤 권장 순서

| 순서 | 작업 | 비용 |
|---|---|---|
| 1 | **`docker compose up -d --build api`** 걸어두기 | 대기 5~15분 |
| 2 | 대기 중 → **화면정의서 PDF 저장** | 5분 |
| 3 | 대기 중 → **WBS 반영** (통합본 → 새 파일) | 30분 |
| 4 | 빌드 완료 후 → **성능 측정** (아래 명령) | 10분 |
| 5 | 표 병합 확인 (원문에 ` | ` 표시 여부) | 5분 |
| 6 | `http.js` 타임아웃 추가 → 커밋·푸시 | 10분 |
| 7 | **N+1 실측** | 1시간 |

### 성능 측정 명령

```powershell
$file = "C:\경로\검토보고서.pdf"

$start = Get-Date
$res = curl.exe -s -X POST http://localhost:8000/api/documents -F "file=@$file"
$sec = ((Get-Date) - $start).TotalSeconds

Write-Host ("소요 {0:N1}초" -f $sec)
$res | ConvertFrom-Json | Select-Object id, char_count, page_count, extract_method
```

**기록할 값 3개**

| 항목 | 이전 값 | 의미 |
|---|---|---|
| 소요 시간 | 약 50초 | `MAX_UPSCALE=2.0` 효과 확인 |
| char_count | 6,986자 | 유지되면 손실 없음 |
| extract_method | HYBRID | 경로 유지 확인 |

### N+1 실측 방법

`app/db/session.py` 의 엔진 생성에 `echo=True` 를 임시로 켜면 실행 SQL이 로그에 출력된다.

```powershell
docker compose logs api --tail 400 > sql.log
Select-String -Path sql.log -Pattern "SELECT" | Measure-Object | Select-Object Count
```

문서 20건 조회 시 **약 41회**(1 + 20×2)가 나오면 N+1 이 확인된 것이다. 개선 후 같은 방법으로 재측정해 감소 폭을 기록한다.

## 8. 발표에 쓸 소재 (확보 완료)

| 주제 | 내용 | 근거 |
|---|---|---|
| **버그 발견 → 해결** | 다운로드 줄바꿈 누락 | HTTP 200·파일명 정상이라 검증을 통과했고, **파일을 열어보지 않아 놓쳤다.** 이후 검증 기준을 '응답 코드'에서 '결과물 내용'으로 변경 |
| | 상세 조회만 500 | 스키마 별칭 설정 때문에 같은 응답을 만드는 두 경로 중 한쪽만 실패. **성공하던 쪽 방식으로 통일**해 재발 차단 |
| | 본문 검색 실패 | 자간 넓은 문서에서 `제안자` 검색 0건. **같은 줄 병합이 OCR 경로에만 적용**된 것을 한 문서의 추출 결과로 증명 |
| **협업 규칙** | main 직접 푸시로 충돌·이력 오염 | 브랜치 전략을 정했으나 지키지 못한 구간에서 충돌 발생. **실제 원인은 '직접 푸시'가 아니라 '푸시 지연'**이었고, 즉시 푸시로 재발 방지 |
| **머지 검증** | 표 검출 좌표계 불일치 | 자동 머지가 충돌 없이 성공했으나 **좌표계 전제가 어긋나 기능이 조용히 무력화.** "머지 통과 ≠ 올바름" |
| **성능 측정** | N+1 쿼리 | 미리 고치지 않고 SQL 로그로 실측 후 개선 → 수치로 개선 폭 제시 |
| | 추출 50초 | 확대 배율 상한으로 완화. 전처리 ON/OFF 실측으로 기여도 분리 |
| **설계 판단** | 전처리를 다 넣지 않음 | 전처리는 정보를 깎는 트레이드오프. 엔진별 최적 조합이 달라 프리셋으로 분리하고 측정 가능하게 설계 |
| | 확장 지점 4곳 | Analyzer Protocol / `document_type` 문자열 / 다운로드 `format` 파라미터 / `LayoutElement` 좌표·신뢰도 |
| | 공통 컴포넌트 레이어 | 강제하지 않았는데 **다른 담당자가 새 화면에서 자발적으로 재사용** → 색·에러 표시가 자동 통일 |
| | 상세 표현 분리 | `DocumentDetail`을 API 비의존으로 만들어 전체화면 ↔ 우측패널 전환 시 **컴포넌트 수정 0** |
| **OCR 엔진 비교** | PaddleOCR vs Tesseract vs EasyOCR | 기각 근거였던 "한국어 정확도"를 주장이 아니라 실측으로 입증 |
