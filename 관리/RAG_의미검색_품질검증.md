## 결론

**`RAG-04` 판정 기준을 실측으로 통과했다.** 구조 완성에서 품질 검증으로 넘어갔다.

기능명세서 546행:

> **글자가 하나도 겹치지 않는 질의**로 관련 문서가 나온다. 다른 프로젝트 문서는 나오지 않는다

## 결과 — 질의 3개 전부 1등이 정확

| 질의 | 1등 | 유사도 | 질의 글자가 본문에 있나 |
|---|---|---|---|
| 사람 인건비를 어떻게 계산했나 | 산출내역서 `1. 직접인건비` | **55%** | "인건비" 부분 겹침 |
| **늦게 끝내면 무슨 불이익** | 입찰공고 `5. 지체상금` | **39%** | **없음** |
| **돈은 언제 받나요** | 입찰공고 `4. 대금 지급` | **53%** | **없음** |

### 왜 이것이 판정 기준을 만족하는가

**"돈은 언제 받나요"** — 본문에 "돈"도 "받나요"도 없다. 그런데
`4. 대금 지급 … 준공 검사 완료 후 30일 이내에 지급한다` 를 1등으로 찾았다.

**"늦게 끝내면 무슨 불이익"** — "지체상금"·"지체 일수"와 글자가 전혀 겹치지 않는다.
그런데 정확히 그 조각을 찾았다.

키워드 검색으로는 둘 다 0건이다. 의미 검색만 할 수 있는 일이다.

## 함께 확인된 것

| | 내용 |
|---|---|
| **프로젝트 격리** | 전체 검색 결과 `14건` = 프로젝트 1(10) + 2(4). **프로젝트 3(남의 것) 청크 2개가 빠졌다** |
| **범위 넘기** | "돈은 언제 받나요" 3등이 착수회의록(다른 프로젝트) — 전체 검색이 실제로 동작한다 |
| **음수 유사도 사라짐** | 가짜 임베더에서 보였던 `-3%`·`-7%` 가 없다. 39~55% 로 나온다 |
| **모델 기록** | 응답과 `document_chunks.embedding_model` 에 `dragonkue/BGE-m3-ko` 가 남는다 |
| **화면 묶기** | `문서 2개 · 조각 10건` · 문서당 2개 펼침 · `이 문서에서 4건 더 보기` |

## 겹침(overlap)이 검색에 실제로 도움이 된 사례

`5. 지체상금` 조각의 구성이다.

```
5. 지체상금                                            <- 제목이 맨 앞
선금은 계약 금액의 70퍼센트 범위에서 지급할 수 있으며…    <- 조각 4번의 꼬리 (겹침)
계약상대자가 준공 기한을 지키지 못한 경우 지체 일수마다…   <- 본문
```

**제목 → 겹침 → 본문** 순서다. 어제 "겹침이 제목을 청크 중간으로 밀어낸다"고 고친
그 동작이다.

그리고 이 겹침 덕분에 **"돈은 언제 받나요" 에 이 조각이 2등(47%)으로 걸렸다** —
선금 이야기가 겹쳐 들어와서다. 겹침의 대가(스니펫에 중복 문장)만 보고 있었는데
이득도 확인됐다.

## 성능

| 구간 | 시간 |
|---|---|
| 검색 전체 | **265~363ms** |
| 그중 DB (벡터 검색) | 3~5ms (청크 6,016개 실측) |
| **그중 질의 임베딩** | **약 250~350ms** |
| 청킹 시 문서 임베딩 | 244~519ms/건 |

**지연의 대부분이 DB 가 아니라 임베딩이다.** 예상대로였다.
실사용에서 문제가 되면 질의 임베딩 캐시나 더 작은 모델을 봐야 한다.

## 유사도 임계값에 대한 근거

| 구간 | 값 |
|---|---|
| 사람이 봐도 정답인 조각 | **39~55%** |
| 하위권 (관련 낮음) | 20%대 |

`min_similarity` 를 **0.3 근처**로 둘 근거가 생겼다. 다만 **질의 3개로 정하기엔
표본이 작다.** 기본값을 넣지 않고 열어 두는 편이 지금은 맞다.

## 운영 메모

| | |
|---|---|
| 모델을 바꾸면 **청킹을 다시 돌려야 한다** | 검색이 `WHERE embedding_model = <현재 모델>` 로 걸린다. 서로 다른 벡터 공간을 섞지 않기 위한 조건이다 |
| `docker compose restart` 는 환경변수를 다시 읽지 않는다 | `up -d` 를 써야 한다 |
| 프론트에 **새 파일**이 생기면 Vite HMR 이 놓칠 수 있다 | `docker compose restart frontend` |
| robocopy 는 크기·시각이 같으면 건너뛴다 | `/E /IS` 로 강제 복사한다 |
