## 작업 규칙 — 반드시 지킬 것

- **커밋·푸시 전에 사용자에게 먼저 보여주고 승인을 받는다.** 임의로 올리지 않는다.
- 자바 · Spring 배경이므로 **새 개념은 Spring 비교로 설명**한다.
- 코드 파일 상단 3단 주석을 유지한다 — 책임 / 다른 파일과의 관계 / Spring 비교
- 문서와 발표자료는 **흑백 무채색**. "다른 사람이 알아볼 수 있으면 충분" 이 기준이다.
- **추측으로 단정하지 않는다.** 코드와 산출물로 확인한 뒤 말한다. 확인이 안 되면
  안 된다고 밝힌다.
- `.yml` 처럼 팀 전체가 공유하는 파일은 혼자 바꾸지 않는다.

## 아키텍처 요점

- 계층 — 라우터 / 서비스 / 리포지토리
- **추출기** `extract(path) -> ExtractResult`, `ExtractorRegistry` 가 확장자별 매핑
- **분석기** `async analyze(text) -> AnalyzeResult`, 요청 필드는 **`analyzer_types`**
- 3테이블 — `documents` 1:1 `extracted_texts` / 1:N `analyses`
  - 카테고리는 `analyses.result_json['category']` (JSONB)
  - `document_type` 은 사람이 붙이는 라벨이고 항상 `general` 이다
  - `analyzer_type` 으로 행을 구분한다 (`summary` / `category`) → 문서 1건에 2행
- `ExtractMethod` — `TEXT_LAYER` / `OCR` / `DOCX` / `HWPX` / **`HYBRID`**
  - PDF 는 PyMuPDF 블록을 순회해 텍스트는 그대로 두고 **이미지 영역만 OCR** 한다.
    OCR 좌표를 PDF 좌표로 되돌려(`inverse_scale`) 같은 기준으로 정렬하므로 이미지 안
    글자가 본문 흐름의 제자리에 들어간다
- AI 타임아웃은 `AI_TIMEOUT_SECONDS` → `AI_TIMEOUT`(504). **재시도와 폴백은 없다**
- 검색은 저장값과 검색어 양쪽에서 공백을 제거해 비교한다 (`regexp_replace` + `ILIKE`).
  본문 검색은 서브쿼리로 분리해 문서 중복 행을 막는다

## 본프로젝트 우선순위

1. OCR 결과를 테이블에 저장 (지금은 즉석 비교만 해서 추이를 못 본다)
2. `cer` 값 노출 + `WER` 추가 — **`CER` 은 이미 구현되어 있다** (아래 정정 참고)
3. LLM 재시도 · 폴백 (타임아웃은 이미 있다)
4. N+1 해소 — 표시용 값 비정규화로 쿼리 20 → 2
5. 전처리 선택 + 비포 / 애프터 화면 (`PRESET_*` 자산 활용)
6. 텍스트 / 이미지 영역 시각화 (이미 나누고 있으니 좌표만 그리면 된다)
7. 3종 병렬 OCR 후 자동 채택
8. 유저 / 개발자 화면 분리
9. 벡터DB + RAG

근거는 `deliver` 레포 `관리/타팀발표_정리.md` 에 있다.
코드로 확인한 재평가와 스코프 안은 `관리/본프로젝트_범위결정_안건.md` 에 있다.

### 정정 — 2번은 이미 CER 이다

`ocr_ground_truth.py` 의 `compute_accuracy()` 는
`max(0, 1 - Levenshtein(정답, 결과) / len(정답)) * 100` 이다. 이것이 CER 의 정의
(`(S+D+I)/N`) 그대로다. 커밋 `f25b58c`(8/5) 에서 들어갔고, 이 문서를 처음 쓸 때
그 커밋을 반영하지 못했다. `ground_truth_accuracy` 라는 **이름 때문에 자체 지표로
보였을 뿐 값은 표준 CER 을 정확도로 뒤집어 표기한 것**이다.

남은 일은 `cer` 값을 응답에 그대로 싣기, `WER` 추가, 공백 정규화 규칙 밝히기 세
가지이며 1번에 붙는 잔업 수준이다.

## 환경 함정

**PowerShell**
- 한글이 든 URL 은 `curl` 로 깨진다 → `[uri]::EscapeDataString()` 로 감싸고
  `Invoke-WebRequest -OutFile` 로 받아 `Get-Content -Encoding UTF8` 로 읽는다
- `Select-String` 은 한글 패턴을 못 찾는다 (ASCII 만)
- `Invoke-RestMethod` 는 한글 응답이 깨진다 (charset 없어 ISO-8859-1 로 디코딩)
- `[...]` 가 든 경로는 `-LiteralPath` 를 쓴다

**psql** — `-c` 하나에 문장 두 개를 넣으면 트랜잭션이 되어 `ALTER SYSTEM` 이 실패한다.
`-c` 를 분리한다.

**docker** — `.env` 를 고친 뒤에는 `docker compose up -d --force-recreate api` 를 쓴다.
`restart` 로는 반영되지 않는다.

**샌드박스** — 네트워크가 차단돼 있고(`INTEGRATIONS_ONLY`) Pillow · python-pptx ·
한글 글꼴이 없다.
- 이미지 자르기와 강조는 `도구/_crop_shot.py` 로 한다 (헤드리스 크롬
  `/usr/local/bin/chrome` 을 쓴다)
- **글자를 이미지로 굽는 것은 불가능하다.** 한글이 □ 로 나온다. 텍스트가 필요한
  산출물은 pptx · md · html 로 만들어 글자를 살린다
